## Status meanings

- **Confirmed working**: recorded hardware confirmation for the stated setup.
- **Partially working**: limited implementation or test coverage; read the feature notes.
- **Reported working**: owner observation awaiting complete reviewed confirmation.
- **Known issue**: recorded failure or unresolved result.
- **Untested**: no sufficient model/platform hardware result.
- **Unknown**: support is not established; do not infer hardware absence.
- **Device does not support it**: evidence establishes that the device lacks this function.
- **Not implemented**: the desktop does not implement this function.
