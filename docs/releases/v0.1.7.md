# v0.1.7 — Equalizers for more headphones and a Multipoint tab

Sony headphones other than the XM6 now get an equalizer, and you can choose which of your devices are connected.

## Equalizer

- Sony headphones other than the WH-1000XM6 describe their own equalizer, and the app now builds the screen from that: the number of bands, the step range, the presets and each band's frequency (including **Clear Bass** on models that have it). Before, only an XM6 on one firmware was ever asked, so other models said the equalizer was unconfirmed.
- Pick a built-in preset, or edit the bands. Presets send only the preset; edits send every band. A change is shown only after the headphone reports it back, and if it does not, the previous profile is written back and verified.
- Headphones that offer presets only get presets and no band editing. A headphone that describes no equalizer says so and points to the diagnostics log.
- The equalizer's text and graph labels are smaller and match the other pages. The XM6 3.1.5 path is unchanged.

## Multipoint

- A new **Multipoint** tab lists the devices your headphone is paired with, with their Bluetooth addresses, whether each is connected, which one plays audio and which one is this computer.
- Switch a device on to connect it, off to disconnect it. A device shows as connected only after the headphone's own list says so. Changes the headphone announces itself, such as another phone connecting, update the list live.
- **At the connection limit, connecting a device first disconnects another.** The one dropped is a connected device that is not playing audio and is not this computer, so the app never cuts its own link. If nothing can be dropped safely, the switch is disabled and says why. The new device is only connected after the other one's disconnection is confirmed.
- The headphone briefly resets its control link while its connections change. That is now reported as a notice that the change most likely went through and the app is reconnecting, not as a failed connection.
- The device playing audio is now read correctly: the headphone names a connection slot, not a position in the list.
- Unpairing is not offered.

## App updates

- The app checks for a new version shortly after it opens and every few hours while it stays open, and shows a **New update available** banner on every page with an **Update now** button and the release notes. **Remind me later** hides it until the next launch.
- **App settings → App updates → Check for updates automatically** turns the background check off. The check contacts the release server, nothing else is sent. When the app is closed to the tray, the check happens the next time you open it.

## Connection and windows

- Starting Sound Connect while it is already running now brings the existing window forward instead of starting a second copy. Two copies shared one WebView2 profile, so one closing left the other as a blank window that did not respond or close.
- A headphone that closes the control link while the app is reading it is retried up to twice. The last attempt skips the optional equalizer and multipoint reads so the core controls still work, and the diagnostics log says so.

## Verification and limitations

Windows, macOS and Linux CI is expected to pass, with 230 native tests, 100 browser tests and 10 browser-companion tests passing locally. The equalizer and multipoint features are covered by wire-level fixtures decoded from the Sony app and have not been exercised on real headphones; the connection limit, the playback slot and the control-link reset behaviour in particular need a hardware check. Multipoint needs a Sony headphone that advertises message table 2, and recognising this computer needs Windows. The Bluetooth address and name of each paired device appear on screen and in diagnostics.

Unpairing, source switching, the Clear Bass function as a separate control and the equalizer user banks are not implemented. Windows WH-1000XM6 firmware 3.1.5 remains the hardware-confirmed Sony baseline; OnePlus support is experimental. macOS control connections remain disabled and Linux control support needs hardware testing. Automatic listening and the listening-history playback details are Windows-only.

## Updating

From **v0.1.2** or later, open **App settings → App updates → Check for updates**, or use the new banner, then choose **Install & restart**. DEB/RPM users install the new package manually; Linux in-app updates require AppImage. Manual downloads include the Windows x64 setup, macOS Apple Silicon and Intel DMGs, and Linux x64 AppImage, DEB and RPM packages, with SHA-256 checksums. Builds are not Apple-signed or notarized, and the Windows installer has no Authenticode publisher signature.

Report issues through the repository's tester-feedback template with your OS, app version and headphone model/firmware.
