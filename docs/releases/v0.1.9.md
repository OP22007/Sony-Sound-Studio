# v0.1.9 — Low-battery alerts, smoother equalizer, lower animation CPU

## New

- The app sends an operating-system notification when a connected headphone's battery drops below 20%. It fires once per drop and re-arms when the battery recovers to 25% or the headphone charges or disconnects. Turn it off under **App settings → Low battery alerts**.

## Fixes and improvements

- The equalizer graph now moves one step at a time while you drag, with a light tick on each step, instead of jumping several steps at once. Grabbing a point no longer shifts it.
- The Sound page's background animations use less CPU (about 17% less in a headless-Edge measurement); it has not been measured in the packaged app.
- Linux: Bluetooth tools now run with a clean environment, and discovery or connection failures report the reason instead of silently showing no headphones.
- macOS: a failed connect releases the device before reporting the error, which fixes a rare race.

## Verification and limitations

Windows, macOS and Linux CI passed. Low-battery notifications were tested in logic and the settings toggle in the browser suite, but not yet against a real headphone's battery drop. macOS control remains experimental and untested on hardware. The Linux discovery fix is unconfirmed on the Ubuntu DEB machine that reported the problem.

macOS builds are not Apple-signed or notarized, and the Windows installer has no Authenticode publisher signature.

## Updating

From **v0.1.2** or later, open **App settings → App updates → Check for updates**, or use the update banner, then choose **Install & restart**. DEB/RPM users install the new package manually; Linux in-app updates require AppImage.

Report issues through the repository's tester-feedback template with your OS, app version and headphone model/firmware.
