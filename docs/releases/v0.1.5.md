# v0.1.5 — Automatic listening that follows what you play

Follow media now chooses settings by what is playing, and only the settings your headphones confirm.

## Automatic listening

- Playback is classified as **game, music, movie or other**. Sony headphones with the upmix series (such as the 1000X COLLEXION) switch between Standard, Cinema, Music and Game; OnePlus earbuds use spatial audio and Game mode where the model advertises them. Head tracking is never chosen automatically.
- A running game wins over background music. Windows game detection is read-only: a full-screen Direct3D app, or a foreground app on a built-in game list. Browsers, media players and launchers are never treated as games.
- Spotify, Apple Music, Tidal, YouTube Music, Spotify web, SoundCloud, Deezer and Amazon Music count as music.
- The page was redesigned around a single "now detecting" readout. Each playback type shows whether your headphones fully support it, partly support it or do not support it, so unsupported modes are never implied.
- Browser companion 1.0.2 pairs with the desktop on its own. Reload it once in your browser after updating (it now asks for the alarms permission).

## Device settings

- **Pause when headphones are removed** can be read and changed on headphones that advertise wear detection.
- Touch sensor control panel, multipoint, voice guidance and similar settings appear when the headphone describes them as General Settings, with their own names and options.
- The XM6's wearing-aware automatic power off is now editable.
- Rows now say whether a headphone did not list a setting, listed it but could not be read, or uses a command group the desktop does not control yet.
- **Focus on voice** is only offered in Ambient sound mode; in other modes the headphone ignored it and the change could not be confirmed.
- Linux RFCOMM channel lookup now handles 128-bit Sony service UUIDs.

## Verification and limitations

Windows, macOS and Linux CI passed, including 179 native tests and 81 browser tests. None of this has been exercised on a headphone yet. The general-settings capability request and set opcode are inferred from matching parsers in the Sony app, and every write still requires matching device readback before the setting shows as changed. Game detection and OnePlus automation need testing with real games and earbuds.

Multipoint paired-device management and the table-2 voice-guidance and notification-tone functions are not implemented. Windows WH-1000XM6 firmware 3.1.5 remains the hardware-confirmed Sony baseline; OnePlus support is experimental. macOS control connections remain disabled and Linux control support needs hardware testing. Automatic listening is Windows-only.

## Updating

From **v0.1.2** or later, open **App settings → App updates → Check for updates**, then choose **Install & restart**. DEB/RPM users install the new package manually; Linux in-app updates require AppImage. Manual downloads include the Windows x64 setup, macOS Apple Silicon and Intel DMGs, and Linux x64 AppImage, DEB and RPM packages, with SHA-256 checksums. Builds are not Apple-signed or notarized, and the Windows installer has no Authenticode publisher signature.

Report issues through the repository's tester-feedback template with your OS, app version and headphone model/firmware.
