# Cross-platform testing preview

Native packages for Windows x64, macOS Apple Silicon, macOS Intel and Linux x64. This is an independent project in development, not a complete replacement for Sony Sound Connect.

## Choose your download

- Windows: `x86_64-pc-windows-msvc-…setup.exe`.
- Apple Silicon Mac: `aarch64-apple-darwin-….dmg`.
- Intel Mac: `x86_64-apple-darwin-….dmg`.
- Ubuntu/Debian x64: `x86_64-unknown-linux-gnu-….deb`.
- Fedora/RPM distributions x64: the `.rpm` package.
- Other compatible Linux x64 systems: the `.AppImage` package; mark it executable before launching. FUSE may be required.

Per-platform SHA-256 checksum files accompany the installers. These builds are unsigned; the macOS builds are not notarized. macOS may block launching this preview. Only proceed with files you trust using the per-app approval in System Settings → Privacy & Security; do not disable Gatekeeper globally. Distribution behavior remains part of testing.

## What to test

Try installation, startup, themes, window/tray behavior, keyboard navigation and the explicit Studio preview. Automatic listening is in its own tab. UI preview never sends headphone commands.

**macOS:** paired-device discovery is implemented; headphone control connections and device settings are disabled. This build is for UI and discovery feedback, not functional headphone-control testing.

**Linux:** BlueZ discovery/RFCOMM is implemented but has not been hardware validated. Install your distribution's packages providing `bluetoothctl` and `sdptool` (commonly `bluez`), enable Bluetooth and pair in OS settings first. Report adapter, distribution and desktop environment with connection results. Do not run the app as root to work around permissions.

**Windows:** XM6 firmware 3.1.5 is the hardware-confirmed baseline for NC mode tracking and a tested EQ-band change. Other settings/models remain capability-gated and require validation.

Automatic listening, system media detection and the optional browser/VLC integration currently require Windows. Automatic Dolby Atmos detection is not implemented. XM5/CH720N hardware validation and complete mobile-app parity remain outstanding.

## Share feedback

Open a [Preview testing feedback issue](https://github.com/OP22007/sony-sound-desktop/issues/new?template=tester-feedback.yml). Include app version, OS/CPU, headphone model/firmware, what worked and reproducible problems. Screenshots and usability reviews are welcome. Remove passwords, pairing keys, device addresses and personal media information from attachments.

The repository is currently private; downloads and feedback become available to outside users when the owner makes it public or grants access.
