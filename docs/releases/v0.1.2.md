# v0.1.2 — Signed desktop preview

This release adds **App settings → App updates** with release notes, download progress and an explicit **Install & restart** action. Signed updater packages and manual installers are available for Windows x64, macOS Apple Silicon, macOS Intel and Linux x64 on this versioned release. The fixed `updater-preview` prerelease carries only the update feed, which points at the versioned packages.

## Updating

Existing installations need one manual update to a build that includes the updater configuration. Download and install the v0.1.2 package for your platform from this release. Later signed versions can then be found through the in-app updater. Back up any important local presets before updating preview builds.

## EQ

The XM6 equalizer now includes Off, Heavy, Clear, Hard, Soft and Game curves, plus a Manual editor and named local profiles you can create, update, rename or delete. Local profiles do not overwrite or synchronize the phone app’s Custom 1/2 slots. EQ controls remain capability-gated; this release does not imply hardware support on every model or operating system. The hardware-confirmed baseline is XM6 firmware 3.1.5 on Windows, covering noise-mode tracking and a tested EQ-band change/readback.

## Platform notes

- **Windows x64:** the updater uses the NSIS setup executable. The package is updater-signed; this does not mean the installer is Authenticode code-signed.
- **macOS Apple Silicon and Intel:** the updater downloads a signed `.app.tar.gz` bundle, while the DMG remains the manual installer. Builds are not notarized, so macOS may require per-app approval in Privacy & Security.
- **macOS device controls:** paired-device discovery is available, but Bluetooth control connections remain disabled.
- **Linux x64:** the updater uses the signed AppImage. Mark it executable; FUSE support may be required. DEB and RPM packages remain available for manual installation.
- **Linux device controls:** BlueZ/RFCOMM is implemented but still needs hardware validation. Automatic listening remains Windows-only.

Signatures let the updater verify that package contents match the publisher's signing key. This is separate from operating-system publisher certification, device hardware compatibility, and release quality. Updates require a network connection to the fixed preview feed.
