# v0.1.4 preview — OnePlus sound controls and a refined desktop studio

This preview adds model-specific OnePlus controls and improves the existing Sony listening workspace.

## Listening and sound

- OnePlus spatial audio uses the model catalog plus live capability and current-value replies. Eligible models expose Off and fixed spatial audio; eligible Buds Pro models can expose head tracking. Legacy firmware uses its own spatial on/off control.
- Game mode remains a separate low-latency switch. Modern Game sound profiles require their own capability and supported-profile readback.
- OnePlus EQ presets, custom curves and profile names use the connected model's layout and device confirmation. BassWave and Sony CLEAR BASS appear where their reported ranges are valid.
- Sony COLLEXION's additional listening modes use their advertised choices. Sony upmix restrictions remain separate from OnePlus spatial controls.
- A setting is confirmed only after matching device readback. Failed confirmation does not send an automatic restoration command.

## Desktop improvements

- The original sidebar layout stays in place, with a more compact device card, refined battery/charging information and themed scrolling.
- Authentic manufacturer artwork sits within distinct listening environments and improved noise-control visuals. Reduced-motion and hidden-window behavior limit animation work.
- Equalizer graph handles support direct dragging and keyboard adjustment with an explicit apply action.
- Windows active-output monitoring follows the connected device. Automatic listening and VLC startup configuration receive reliability fixes.

## Validation and limitations

Validation: 139 native tests passed (5 hardware tests ignored), all 79 browser tests passed before the final UI validation tightening, its 3 focused browser tests passed afterward, and 12 extension/release-script tests passed. Production frontend compilation passed.

The new OnePlus spatial and Game sound paths are protocol-researched and fixture-tested; they still need user-operated hardware validation. Model catalog entries alone do not enable settings. Android phone-rendered spatial audio, Dolby/Atmos decoding and platform head-tracker integration are not added by these Bluetooth controls.

Windows WH-1000XM6 firmware 3.1.5 remains the confirmed Sony baseline. OnePlus support is experimental. macOS control connections remain disabled; Linux control support needs hardware testing. Automatic listening is Windows-only.

This preview is packaged locally for Windows x64 because GitHub Actions reports an account billing lock. Cross-platform artifacts and protected-main integration remain pending restoration of CI. The Windows updater signature is separate from Authenticode publisher signing. Install this preview manually; the stable updater feed is unchanged.
