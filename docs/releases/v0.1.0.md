# v0.1.0 — Windows preview

Independent desktop companion for Sony headphones, built with Tauri 2, Rust and React.

- Sound Studio with official model artwork, listening-mode scenes, EQ visualization and reduced-motion support.
- Dedicated Automatic listening tab with opt-in Standard/Cinema switching, browser companion pairing and optional VLC localhost integration.
- Windows Bluetooth discovery, device information, capability-gated controls and device readback confirmation.
- Local app preferences, saved EQ presets, tray lifecycle and explicit studio preview.

## Installation

Download the Windows x64 setup executable and run it. Pair your headphones in Windows Bluetooth settings, then find and connect them in the app. Windows may show an unsigned-app warning; this preview is not code-signed.

For browser media detection, extract the Chromium companion ZIP and load its folder as an unpacked extension. Pair it from the Automatic listening tab. The Firefox archive is for temporary loading/development and is unsigned. Existing companion users should reload the updated extension and pair again.

VLC requires its Web interface to be enabled with a password; setup and connection testing are available in the Automatic listening tab. Automation is opt-in.

## Validation and limitations

- 28 browser integration tests, 59 Rust unit tests and 8 browser-companion tests passed during release preparation.
- WH-1000XM6 firmware 3.1.5 on Windows has hardware confirmation for noise-control mode tracking and a tested EQ-band change/readback. This does not establish every control on every model.
- Windows can omit VLC from system media sessions; use the optional direct VLC connection. Full playback validation of that connector remains outstanding.
- Known streaming movies/shows request Cinema; ordinary browser media requests Standard. Automatic Dolby Atmos detection is not implemented.
- XM5/CH720N and macOS/Linux hardware validation remain outstanding. No macOS/Linux binaries are included.
- Full Sony mobile-app feature parity is not achieved. Unsupported controls remain gated.

See the repository README and evidence reports for validation scope and artwork attribution. APKs, decompiled app content and private research captures are excluded.
