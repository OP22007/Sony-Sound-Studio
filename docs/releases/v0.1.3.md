# v0.1.3 — A cleaner listening workspace

**Equalizer now has its own tab.** Sound Studio keeps the animated Sony headphone artwork with Sound mode and Noise control arranged together below it.

## What's changed

- A dedicated Equalizer workspace contains the full editor, Sony presets, named local custom profiles and supported DSEE controls.
- The wider EQ curve aligns with all ten sliders, including at narrow widths; every band stays reachable without horizontal scrolling.
- Sound Studio places sound modes and noise control on one divided surface, with aligned choices and a stacked layout on smaller screens. The duplicate noise illustration has been removed.
- Navigation wraps into two readable rows on narrow screens. Muted text has improved contrast in the light theme.
- Returning from Equalizer preserves the headphone scene's response to bass and treble changes. The scene is unmounted while you use another tab.

Selected devices, confirmed headphone settings and saved local profiles retain their existing behavior. This release changes the interface; it does not add Bluetooth commands or expand model support.

## Updating

From **v0.1.2**, open **App settings → App updates → Check for updates**, then choose **Install & restart**. The updater verifies the artifact signature and signed version before installation. DEB/RPM users install the new package manually; Linux in-app updates require AppImage. Versions before v0.1.2 need a manual installer upgrade first.

Manual downloads include Windows x64 setup, macOS Apple Silicon and Intel DMGs, and Linux x64 AppImage, DEB and RPM packages. Per-platform SHA-256 checksums are included. The `.sig` files and macOS `.app.tar.gz` packages support the in-app updater.

## Verification and support

The UI change passed 45 browser tests, production frontend compilation and Windows/macOS/Linux CI. Checks cover preset persistence, keyboard EQ adjustment, native pending/error states, reduced motion and layout at 1440, 960 and 390 pixels. Dark and light desktop/mobile renders were inspected. Hardware was not operated for this layout change.

- Windows WH-1000XM6 firmware 3.1.5 remains the hardware-confirmed baseline for noise-mode tracking and a tested EQ-band change/readback. Other models and controls need further validation.
- macOS supports paired-device discovery; headphone control connections remain disabled. Builds are not Apple-signed or notarized, so Gatekeeper approval may still be needed. Updater signatures are separate from Apple notarization.
- Linux BlueZ/RFCOMM support still needs hardware testing. Automatic listening remains Windows-only.
- The Windows installer is updater-signed, without Authenticode publisher signing.

Report issues through the repository's tester-feedback template with your OS, app version and headphone model/firmware.
