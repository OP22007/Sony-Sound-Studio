A FEW GOOD QUESTIONS

Before you
press play.

Is this the official Sony app?+

No. Sony Sound Studio is an independent, open-source project, unaffiliated with Sony or OnePlus. It brings supported headphone controls to the desktop and does not yet offer full Sound Connect feature parity.

Will every feature work with my headphones?+

Features depend on your model, firmware and operating system. Controls appear when the app has established the relevant capabilities and current values. XM6 on Windows is our tested baseline; XM5, CH720N, Linux and OnePlus need further hardware validation. macOS control connections remain disabled.

Does Cinema add spatial audio to any headphones?+

No. Native Cinema processing runs inside supported headphones. The desktop app switches that device feature; it does not add the algorithm to unsupported models. The sound field on this website is an interactive visual demonstration.

How do I get started?+

Download your platform’s package from GitHub Releases and read its installation notes. Pair your headphones in operating-system settings first, power them on, then use Find headphones in the app. Studio preview is available if you want to explore without a connection.

Can I help build it?+

Absolutely. Testing real hardware, improving platform support, accessibility, documentation and interface design all help. Start with the contribution guide or share testing feedback.
